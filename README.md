# Gliwice Runner

Prosty prototyp gry typu endless runner zrobiony w Godot 4.7.2.

Instrukcje:
1) Pobierz repo i otwórz w Godot 4.7.2.
2) Otwórz projekt (project.godot). Główna scena: res://scenes/Main.tscn
3) Pliki znajdują się w folderach scenes/ i scripts/. Modele są placeholderami używającymi prostych MeshInstance3D.
4) Aby podmienić na własne modele pociągów/autobusów, wgraj pliki .glb do folderu res://assets/ i ustaw PackedScene w ObstacleSpawner.
